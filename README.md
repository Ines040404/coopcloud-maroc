# CoopCloud Maroc

Plateforme de vente en ligne pour les coopératives marocaines.
Les clients consultent les produits, passent commande et simulent un paiement.

## Répartition du travail

- Personne A — service Stock sur Google Cloud, service Paiement sur AWS et déploiement du site web.
- Personne B — service Commandes sur Azure, service Coopératives sur Oracle Cloud et connexion avec Microsoft Entra ID.
- En commun — développement des écrans du site et tests du parcours d’achat.
